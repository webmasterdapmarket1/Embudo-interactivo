# Regla de Tipografía y Estilo Visual

- **Urbanist**: Tipografía principal obligatoria para títulos, subtítulos, textos generales, descripciones y canvas.
- **Syne**: Tipografía exclusiva para énfasis y botones (ej: `.mode-btn`, `.main-cta-button`).
- **Límite de peso para Syne**: Máximo peso **600** (`font-weight: 600` o 500). Nunca usar valores superiores a 600.
- **Prohibido**: Alterar estas fuentes o cambiarlas por fuentes como Plus Jakarta Sans o Roboto.
